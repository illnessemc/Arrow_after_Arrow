# 一箭又一箭（多格折线版）

这是一个使用 Python 和 Pygame 开发的网格箭头解谜游戏。在课程基础玩法
之上，当前版本已经支持占据多个格子的直线和折线箭头，并为关卡生成、
棋盘形状和玩法规则预留了可替换接口。

## 当前功能

- 开始、游戏、通关和失败页面；
- 上、下、左、右四种头部方向；
- 多格直线箭头与多转角折线箭头；
- 点击箭头身体的任意格子选择整支箭头；
- 判断箭头头部到棋盘边界之间是否存在其他箭头；
- 路径畅通时飞出，受阻时晃动并扣除失误机会；
- 显示当前关卡、剩余箭头和剩余失误次数；
- 重新开始当前关卡；
- 折线沿路径逐段抽出棋盘的动画；
- 测试关、教学关和正式关各一关，箭头占满全部可玩格。

## 运行方法

建议使用 Python 3.10 或更高版本。

```bash
python -m pip install -r requirements.txt
python main.py
```

鼠标左键点击箭头，按 `Esc` 或关闭窗口退出。

## 核心模块说明

### `Arrow`

一支箭头不是简单保存一个位置，而是保存从尾部到头部的连续坐标序列：

```python
# 当前单格箭头
Arrow("A", ((2, 3),), Direction.RIGHT)

# 后续可使用的直线箭头
Arrow("B", ((2, 1), (2, 2), (2, 3)), Direction.RIGHT)

# 后续可使用的折线箭头
Arrow("C", ((1, 1), (2, 1), (3, 1), (3, 2)), Direction.RIGHT)
```

类内部会检查重复格子和路径连续性。`head` 始终表示路径最后一个格子，
`direction` 表示头部最终朝向。

### `GameBoard`

地图类保存布局、全部箭头以及“格子 -> 箭头 ID”的占用索引。放入或移除
多格箭头时，它会一次更新全部身体格。阻挡检测从箭头头部沿最终方向逐格
扫描，每个格子的查询都是常数时间；对于当前小棋盘无需增加更复杂的索引。

### `BoardLayout`

布局对象独立描述哪些坐标属于可玩棋盘。目前三关使用完整矩形，后续可以
传入自定义 `playable_cells` 表示缺角或带空洞的异形棋盘。

### `Level`

关卡是不会被游戏过程修改的初始模板。每次开始或重新开始时，它都会创建
一块新的 `GameBoard`。当前关卡开启全覆盖校验：只要有遗漏格、越界、路径
重叠或重复 ID，构建阶段就会立即报错。

### `LevelBuilder`

`ManualLevelBuilder` 用有序坐标逐支填写箭头，第三关仍采用这种明确可调整的
设计方式。`LevelBuilder` 协议为后续模板生成、随机生成或文件读取保留统一
入口，新的生成器最终仍返回 `Level`，无需改游戏主循环。

### `GameSession`

游戏会话处理一次关卡中的可变状态：玩家点击、失误次数、是否通关和是否
失败。出界判断通过 `ExitRule` 注入，当前使用保持基础玩法不变的
`StraightExitRule`；以后增加特殊出口或转向规则时可替换规则对象。

### `app.py`

应用层接收鼠标事件，将网格坐标交给 `GameSession`，然后根据返回结果播放
飞出或碰撞反馈。它负责“怎么显示”，核心层负责“结果是什么”。

## 关卡定位

- 第 1 关“路径测试”：4×4，用于检查多格、折线、身体点击和连锁释放；
- 第 2 关“折线教学”：5×5，用清晰的单链顺序说明玩法；
- 第 3 关“回环交错”：7×7，正式的手工路径关卡。

三关分别覆盖 16、25、49 个格子且没有空位。当前仍保留基础直线出界规则，
尚未加入机关、提示、Solver、评分或存档。
