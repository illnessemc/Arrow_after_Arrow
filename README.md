# 星箭迷途

当前版本：`v1.0`

这是一个使用 Python 和 Pygame 开发的网格箭头解谜游戏。当前版本以“密集、
简洁、整条折线逐段抽出”为主要表现：箭头可以占据多个格子并多次转弯，
第 1 关使用稀疏布局教学，正式关和无尽关会铺满全部可玩格。

## 当前功能

- 开始、游戏、通关和失败页面；
- 多格直线箭头与多转角折线箭头；
- 点击箭头任意线段选择整支箭头；
- 箭头沿自身路径像蛇一样逐段前进并飞出棋盘；
- 受阻时向前试探、变红、晃动并扣除失误机会；
- 箭身使用圆角连接和加粗圆形尾端；
- 飞出动画按圆角曲线弧长连续滑动；
- 动画播放时仍可继续点击，合法操作按顺序进入动画队列；
- 箭头使用四倍分辨率整条描边后平滑缩小，减少斜边和圆角毛刺；
- 只在未被箭头占用的可玩格显示棋盘点，动画离开后再显出；
- 飞出时经过的棋盘点会依次放大再恢复，形成低对比度单色拖尾；
- 棋盘尺寸按关卡配置，界面会自动缩放；
- 深色纵向布局和确定性的多色箭头，相邻箭头不会同色；
- 首页、游戏背景、标题、Logo、按钮、设置、生命和结果页已接入星空主题素材；
- 1 个稀疏手工教学关和 5 个自动生成的正式关；
- 正式关同时包含大尺寸矩形和“凸”字形棋盘；
- 自动生成、完整覆盖检查和通关流程验证；
- 固定关卡使用固定种子，同一版本可以稳定复现；
- 无尽模式每关使用新随机种子在线生成，并在进入游戏前验证可通关性；
- 开始界面可选择任意关卡并提供退出按钮，齿轮或 `Esc` 用于唤出菜单；
- 普通启动不提供调试能力，`--debug` 版本可强制移除箭头和切换关卡。

## 运行方法

建议使用 Python 3.10 或更高版本。

```bash
python -m pip install -r requirements.txt
python main.py
```

需要调试关卡时使用独立启动参数：

```bash
python main.py --debug
```

鼠标左键点击折线箭头。游戏内按 `Esc` 打开设置，开始界面按 `Esc` 或关闭
窗口退出。

## 核心设计

### 箭头和地图

`Arrow` 保存从尾部到头部的连续坐标序列，支持任意长度和多个直角转弯。
`GameBoard` 保存“格子 -> 箭头 ID”的占用索引，放入和移除箭头时会统一更新
全部身体格。点击线段任意位置都能找到整支箭头。

阻挡检测只需从箭头头部沿最终方向扫描。每个格子的占用查询为常数时间，
扫描成本与头部到棋盘边界的距离成正比；当前棋盘规模无需增加复杂空间索引。

### 动态棋盘

`BoardLayout` 独立描述棋盘行列数和可玩坐标，界面根据当前尺寸计算格子大小，
并未把玩法限定为固定的 7×9。生成规格可通过 `playable_cells` 使用缺角、
带空洞或多边形轮廓；当前最后一关使用上窄下宽的“凸”字形棋盘。

### 自动关卡生成

正式关采用在线、确定性生成：程序启动时根据 `GeneratedLevelSpec` 和固定种子
生成路径，无需逐支手写箭头。`INTERLEAVED` 策略把地图拆成方向交替的矩形带；
`NESTED_RINGS` 和 `MIXED_REGIONS` 仍可用于特定主题关。当前正式关使用
`GLOBAL_WEAVE`：先构造一条覆盖整个棋盘的连续路径，在全图范围内扰动后统一
切分，不再把棋盘分成互不相关的区域。混合阶段会从路径两端做变换，并用局部
换边主动打断长直线；切分时优先落在转角附近，避免把一条长路径机械拆成一列
同向短箭头。每个片段会分别尝试正向和反向，生成器按实际出界路径为其定向，
从而在保持全局交织的同时直接构造可解顺序。
`ArrowShapeMix` 控制直线、单转角、多转角箭头的相对权重。生成结果必须满足
四方向数量、三类箭头最低占比、折线占比、短箭头占比、形状重复率和平均可选
数等质量门槛，避免整关退化成单一构图。

`ArrowShapeLimits` 单独限制不同形状允许达到的长度。当前直线最多 6 格、单转角
最多 14 格，任意箭头在单个坐标轴上最多横跨 9 格；超过 14 格的箭头必须至少
转弯两次。因此较长箭头会形成紧凑折线路径，不会用浅 U 形横跨整张棋盘。

生成器在为片段选择方向时，不只检查能否通关，还会优先让它的出界射线经过
已经排入移除顺序的箭头，并优先让最近阻挡者来自另一方向。质量验收会同时
统计完整射线和最近阻挡关系：初始可直接飞出的箭头不能超过 20%，平均每支
箭头至少有 2 条依赖，跨方向依赖至少占 65%，只受同向箭头限制的箭头不超过
受限箭头的 10%，最近阻挡者同向的比例不超过 40%，连续同向制约链最多包含
3 支箭头，最大关联分量必须覆盖至少 90% 的箭头。

增加一关只需要追加规格：

```python
GeneratedLevelSpec(
    "新关卡",
    rows=12,
    cols=14,
    seed=20260925,
    min_arrow_length=6,
    max_arrow_length=16,
    boundary_break_chance=0.2,
    coverage_pattern=CoveragePattern.GLOBAL_WEAVE,
    shape_mix=ArrowShapeMix(
        straight=0.3,
        single_turn=0.4,
        multi_turn=0.3,
    ),
    shape_limits=ArrowShapeLimits(
        max_straight_length=6,
        max_single_turn_length=14,
        max_axis_span=9,
    ),
    nested_region_ratio=0.35,
    vertical_region_ratio=0.5,
)
```

`LevelGenerator` 是自动生成接口；以后可以并列增加模板拼接、文件读取或更复杂
的生成算法。生成结果仍是统一的 `Level`，不需要修改游戏主循环。

### 全覆盖和流程验证

关卡创建时会检查越界、路径断裂、格子重叠和重复 ID。正式关及无尽关使用
`CoverageMode.REQUIRE_FULL`，每个可玩格必须恰好属于一支箭头；第 1 关显式
使用 `CoverageMode.ALLOW_EMPTY`，用较少箭头突出基础阻挡关系。

`LevelSolver` 使用与正式游戏相同的规则尝试清空棋盘。当前基础规则具有单调性：
移除箭头只会减少阻挡，所以每步选择任意可飞出的箭头即可完成可靠验证；若某
一步没有可选箭头，关卡会在载入前被拒绝。求解报告还记录步骤数和每步可选数，
为后续关卡排序及难度曲线预留数据。

### 手工教学关

第 1 关“方向入门”是 9×8 稀疏手工关，6 支箭头形成清晰的教学依赖链。
后续 5 关尺寸分别为 22×16、26×18、30×20、28×20 和 30×20，均由生成器
构造并由求解器验证；第 6 关只启用“凸”字轮廓内的 500 格。所有正式关均
完整覆盖可玩格，无空位、无重叠。

### 无尽模式

`EndlessLevelFactory` 在玩家点击“无尽模式”或完成当前无尽关后才生成下一关。
每轮从系统随机源取得新种子，候选仍经过完整覆盖、质量策略和 `LevelSolver`
验证；单个种子未达标时自动换种子，达到尝试上限则显示可重试提示，不会让
程序崩溃。棋盘尺寸随轮次缓慢增加并封顶为 30×20，以控制生成时间和内存。

### 规则扩展

`GameSession` 负责点击、失误次数和输赢状态；出界判断通过 `ExitRule` 注入，
当前仍使用基础的 `StraightExitRule`。以后增加特殊出口、转向、机关或新的
棋盘形状时，可以替换规则或生成器，而不用把逻辑堆进 Pygame 界面层。

### 界面资源扩展

`GameTheme` 集中保存界面颜色，箭头配色由邻接图自动分配，相邻箭头不会使用
同一种颜色。`AssetProvider` 为开始、选关、设置、游戏、生成中、结果和失败页
背景，以及标题、Logo、设置图标、生命、星星、通关图标、失败图标和按钮保留
语义资源键。`DirectoryAssetProvider` 默认从 `resource/image` 加载并缓存素材，
自动裁掉透明留白；缺少单项素材时仍会回退到文字和 Pygame 图元。

应用退出时会统一清空动画、颜色表和素材缓存，再调用 `pygame.quit()`。
重新开始或切换关卡会用新 `GameSession` 替换旧棋盘并清空表现状态。固定自动
关只在模块加载时生成一次；无尽模式只保存当前关，下一关替换上一关，不缓存
历史地图。程序不写入关卡文件，也不会启动网络服务或占用端口。

### 连续操作与动画

核心规则在点击时立即更新棋盘，`AnimationQueue` 保存对应的表现快照并按点击
顺序播放。后续合法箭头无需等待当前动画结束即可继续点击；尚未播放的箭头仍
保持静态显示。阻挡动画排队期间会锁定同一箭头，防止快速重复点击被多次扣除
机会。重新开始、切关或返回首页时会同时清空动画状态。

## 生成方式选择

本版本选择在线生成而不是保存离线关卡文件。当前算法只处理一条全覆盖路径、
局部路径变换和有限次数的候选重试；固定关卡在启动时只生成一次，固定种子也
保证结果可复现。若以后加入全局搜索、复杂机关或高成本难度优化，可以保持
相同接口，把已验证的生成结果序列化为离线关卡以缩短启动时间。

教学关路径直接保存在 `levels.py` 中。自动关只保存尺寸、种子和生成参数，
启动时生成到内存中的 `Level` 模板；重新开始或再次进入关卡只从该模板重建
棋盘，不会重新随机。无尽关仅在继续挑战时重新取随机种子，并立即丢弃上一关
的运行时引用；程序不会把关卡写入磁盘，也不会随着游玩轮次持续占用存储空间。
