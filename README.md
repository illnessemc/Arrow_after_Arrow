# 一箭又一箭（项目骨架与基础规则）

这是一个使用 Python 和 Pygame 开发的网格箭头解谜游戏。目前先完成可扩展
的项目骨架与课程要求中的单格箭头规则，不加入额外美术素材、复杂机关、
Solver 或存档等扩展功能。

## 当前功能

- 开始、游戏、通关和失败页面；
- 上、下、左、右四种单格箭头；
- 鼠标点击箭头；
- 判断箭头头部到棋盘边界之间是否存在其他箭头；
- 路径畅通时飞出，受阻时晃动并扣除失误机会；
- 显示当前关卡、剩余箭头和剩余失误次数；
- 重新开始当前关卡；
- 三个基础关卡。

## 运行方法

建议使用 Python 3.10 或更高版本。

```bash
python -m pip install -r requirements.txt
python main.py
```

鼠标左键点击箭头，按 `Esc` 或关闭窗口退出。

## 核心模块说明

### `Arrow`

一支箭头不是简单保存一个位置，而是保存从尾部到头部的连续坐标序列：

```python
# 当前单格箭头
Arrow("A", ((2, 3),), Direction.RIGHT)

# 后续可使用的直线箭头
Arrow("B", ((2, 1), (2, 2), (2, 3)), Direction.RIGHT)

# 后续可使用的折线箭头
Arrow("C", ((1, 1), (2, 1), (3, 1), (3, 2)), Direction.RIGHT)
```

类内部会检查重复格子和路径连续性。`head` 始终表示路径最后一个格子，
`direction` 表示头部最终朝向。

### `GameBoard`

地图类保存行列大小、全部箭头以及“格子 -> 箭头 ID”的占用索引。放入或
移除多格箭头时，它会一次更新全部身体格。阻挡检测从箭头头部沿最终方向
逐格扫描，因此当前单格规则和以后多格/折线箭头可以共用地图接口。

### `Level`

关卡是不会被游戏过程修改的初始模板。每次开始或重新开始时，它都会创建
一块新的 `GameBoard`，所以不需要手工恢复已经消除的箭头。

### `GameSession`

游戏会话处理一次关卡中的可变状态：玩家点击、失误次数、是否通关和是否
失败。它不导入 Pygame，也不负责动画；界面变化不会影响规则判定。

### `app.py`

应用层接收鼠标事件，将网格坐标交给 `GameSession`，然后根据返回结果播放
飞出或碰撞反馈。它负责“怎么显示”，核心层负责“结果是什么”。

## 当前扩展边界

数据结构已经允许创建多格直线和折线箭头，地图也能管理它们的格子占用；
但当前界面仍只绘制单格箭头，飞出动画也是基础直线动画。后续实现多格、
拐弯和蛇形飞出时，应扩展绘制与动画策略，而不是修改基础点击规则。
